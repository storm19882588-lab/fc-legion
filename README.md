# FC LEGION — сайт футбольного клубу

Готовий адаптивний сайт українською: головна, склад, матчі, статистика, новини, медіа та панель керування. Без платних бібліотек.

## Швидкий перегляд

Відкрийте `index.html` у браузері (для модульного JavaScript може знадобитися локальний сервер, наприклад `python -m http.server 8000`). Без Firebase сайт працює у **деморежимі**: зміни зберігаються **лише у поточному браузері** через localStorage. Вони НЕ синхронізуються з іншими відвідувачами. Можна експортувати та імпортувати JSON.

## Безкоштовна публікація + спільне керування

1. Створіть безкоштовний проєкт на https://console.firebase.google.com/ . Додайте вебзастосунок у Project settings → Your apps та скопіюйте `firebaseConfig` у `firebase-config.js` (apiKey, authDomain, projectId, appId).
2. Firebase Console → Authentication → Sign-in method → увімкніть **Google**. У Authentication → Settings → Authorized domains додайте домен вашого майбутнього сайту (наприклад `yourname.github.io`).
3. Firebase Console → Firestore Database → Create database. Відкрийте Rules та вставте вміст `firestore.rules`, потім натисніть Publish. **Не залишайте тестові правила з відкритим записом!**
4. Створіть репозиторій GitHub (можна публічний), завантажте файли сайту в корінь репозиторію. У Settings → Pages → Build and deployment виберіть Deploy from a branch, `main`, `/ (root)`. Посилання матиме вигляд `https://USERNAME.github.io/REPOSITORY/`. GitHub Pages має безкоштовний тариф для публічних репозиторіїв. Альтернатива — безкоштовний Cloudflare Pages.
5. Перейдіть на опублікований сайт → «Керування» → «Увійти через Google». Ви побачите свій **UID**. Скопіюйте його.
6. У Firebase Console → Firestore Database → Data вручну створіть колекцію `roles`, документ з **ID рівним вашому UID**, поле `role` типу string зі значенням `admin`. Це одноразова безпечна ініціалізація головного адміністратора. Оновіть сторінку / увійдіть знову.
7. Для другого адміністратора: попросіть його увійти через Google і надіслати свій UID. У колекції `roles` створіть документ з його UID і полем `role` = `editor` (або `admin`, якщо довіряєте повний доступ). `editor` може змінювати контент, але не ролі. Після зміни ролі користувач має оновити сторінку.

### Як редагувати

Відкрийте `#admin` на сайті. У вкладках «Гравці», «Матчі», «Новини», «Відео» додавайте та змінюйте записи. Для фото вставляйте публічне HTTPS-посилання на зображення (файли не завантажуються на сервер). Для відео вставляйте посилання YouTube. У статистиці відображаються значення, які ви внесли в картку гравця.

### Важливо

- **Це не WordPress-тема.** ZIP не можна завантажити як тему на безкоштовний WordPress.com. Це окремий сайт для GitHub Pages / Cloudflare Pages.
- Firebase має безкоштовні квоти, але перевищення лімітів чи майбутні зміни тарифів можуть вимагати оплати. Перевіряйте актуальні умови провайдерів.
- Без налаштування Firebase всі зміни локальні, і доступу інших адміністраторів до спільних даних немає.
- Не розміщуйте приватні дані гравців без їхньої згоди. Контент у Firestore читається публічно.
- Файл `firebase-config.js` не є секретним: захист забезпечують **Firestore Security Rules**, а не приховування конфігурації.
